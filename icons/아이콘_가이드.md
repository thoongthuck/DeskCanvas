# 아이콘·이미지 가이드 (포스트잇 · 팝업 메뉴 · 설정 창 · 쪽지 스타일·템플릿)

> 이 폴더(`code/icons/`)에 추가한 이미지가 각각 **어디에, 어떤 크기로, 어떤 조건에서** 쓰이는지 정리한 문서입니다. 구현 담당 AI가 읽는 용도입니다.
> - 포스트잇 (1~5장): 기준 시안 `디자인/포스트잇-기능.png` · 한눈에 보기 `아이콘_미리보기.png`
> - 팝업 메뉴 — 쪽지 추가·설정·종료 (6장): 기준 시안은 사용자가 따로 전달한 팝업 메뉴 시안 · 한눈에 보기 `팝업메뉴_미리보기.png`
> - 설정 창 (7장): 기준 시안은 사용자가 따로 전달한 설정 창 시안 · 한눈에 보기 `설정창_미리보기.png`
> - 쪽지 스타일·템플릿 (8장): 기준 시안 `시안_쪽지스타일.png` · `시안_쪽지템플릿.png` (이 폴더, 사용자 확인 받음) · 한눈에 보기 `템플릿_스타일_미리보기.png`
> - 글꼴 (11장): `code/fonts` — 쪽지 스타일·코드 칸에 쓰는 무료 글꼴 4종
> - 판 — 캘린더 · 연대표 (12장): 기준 시안 `시안_캘린더판.png` · `시안_연대표판.png` · 한눈에 보기 `판사진_미리보기.png`
> - 사진 틀 (13장): 기준 시안 `시안_사진틀.png`
> - 기본 파일 아이콘 (14장): 한눈에 보기 `파일아이콘_미리보기.png`
> - 우클릭 메뉴 시안: `디자인/팝업/팝업.png`
> - 미리보기 PNG에는 파일명·용도·조립 예시가 그림으로 정리되어 있습니다.

## 0. 공통 규칙

- 전부 SVG이며 **색이 파일 안에 들어 있습니다** (`currentColor` 아님). `<img src>` 또는 CSS `background-image`로 그대로 쓰면 됩니다. CSS `color`로는 색이 바뀌지 않습니다.
- SVG의 `width`/`height` 값 = **권장 표시 크기**. 포스트잇 에셋은 zoom 1 기준이므로 캔버스 zoom 배율을 곱해서 표시하세요. (현재 코드가 노트 크기에 zoom을 곱하는 방식과 동일하게, 아이콘 크기·접힘 크기에도 곱하면 됩니다.) 팝업 메뉴·설정 창 아이콘은 캔버스와 무관하므로 zoom을 곱하지 않습니다. 팝업 메뉴는 24px 그대로, 설정 창은 7-3 표의 표시 크기(24 기준 그림을 32·28px로 키움)를 따릅니다. 쪽지 머리 아이콘(`note-code`·`note-markdown`)과 코드 칸 버튼은 쪽지 안에 있으므로 zoom을 곱합니다.
- 경로: JS에서는 `renderer.js`의 `ICON_DIR`(`'./icons/'`)에 파일명을 붙이면 되고, CSS(`styles.css`)에서는 `url("icons/파일명.svg")`로 불러옵니다.
- 파일 안의 gradient/filter/mask id는 파일마다 고유하므로 SVG를 DOM에 인라인으로 넣어도 충돌하지 않습니다.
- 노트 위 아이콘의 기본 잉크색은 `#1F2F45`, 선 굵기는 2px(24px 기준)입니다. 팝업 메뉴·설정 창 아이콘은 파일마다 색이 다릅니다(6장·7장).

## 1. 포스트잇 — 파일별 기능

### 1-1. 노트 헤더 아이콘 — 24px

| 파일 | 모양 | 들어가는 곳 | 언제 표시하나 |
|---|---|---|---|
| `note-text.svg` | 글줄이 있는 문서 | 헤더 왼쪽 | 텍스트 메모 (기본 상태) |
| `note-image.svg` | 산·해가 그려진 액자 | 헤더 왼쪽 | 이미지가 들어간 메모 (기본 상태) |
| `note-checklist.svg` | 체크된 사각형 | 헤더 왼쪽 | 할 일(체크리스트) 메모 (기본 상태) |
| `note-pinned.svg` | 세워진 압정 | 헤더 왼쪽 | **고정된 노트** — 메모 종류 아이콘 대신 표시 |
| `note-selected.svg` | 파란 원 + 흰 체크 | 헤더 왼쪽 | **선택된 노트** — 다른 아이콘 대신 표시 |
| `note-more.svg` | 가로 점 3개 (반투명) | 헤더 오른쪽 | 항상 표시. 클릭하면 우클릭 메뉴와 같은 메뉴를 그 자리에서 여는 것을 권장 |
| `note-emoji.svg` | 웃는 얼굴 | (선택) 이모지 넣기 버튼 | 시안의 아이콘 목록에만 있고 배치 위치는 시안에 없음 |

- 헤더 왼쪽 아이콘 우선순위: **선택됨 > 고정됨 > 메모 종류**
- `note-more.svg`는 45% 반투명이라 노트 색이 비쳐서 색마다 톤이 자동으로 맞습니다.

### 1-2. 할 일 체크박스 — 20px

| 파일 | 모양 | 들어가는 곳 | 언제 표시하나 |
|---|---|---|---|
| `checkbox.svg` | 빈 네모 | 할 일 항목 맨 앞 | 미완료 |
| `checkbox-checked.svg` | 채워진 네모 + 흰 체크 | 할 일 항목 맨 앞 | 완료. 클릭할 때마다 두 파일을 서로 바꿔 표시 |

- 체크박스와 글자 사이 간격 8px. 완료된 항목 글자는 취소선 + 투명도 0.5를 권장합니다.

### 1-3. 우클릭 메뉴 — 이번에 추가한 파일 없음

- 우클릭 메뉴는 이미 있는 파일을 그대로 씁니다: `edit.svg`(수정하기), `copy.svg`(복사하기), `pin.svg`(고정하기), `palette.svg`(색상 변경), `trash.svg`(삭제하기), `chevron.svg`(하위 메뉴 화살표). `renderer.js`에 이미 연결되어 있습니다.
- `wrench.svg`는 현재 코드에서 쓰이지 않으며, SVG 네임스페이스(`xmlns`)가 없어 `<img>`로 표시되지도 않는 파일입니다. 사용하지 마세요.

### 1-4. 접힌 모서리 — 28px (노트 오른쪽 아래)

| 파일 | 짝이 되는 노트 색 |
|---|---|
| `fold-yellow.svg` | 노랑 `#FDF2C2` |
| `fold-pink.svg` | 분홍 `#FDE0E3` |
| `fold-blue.svg` | 파랑 `#DCECFC` |
| `fold-green.svg` | 초록 `#E0F4E2` |
| `fold-purple.svg` | 보라 `#E4E0FC` |
| `fold-gray.svg` | 회색 `#EFF0F0` (비활성 상태에도 사용) |

- 파일 한 장에 **노트 배경색 영역 + 접힌 면 + 접힌 선 바깥의 투명한 부분(옅은 그림자)** 이 모두 들어 있습니다. 접힌 선 바깥은 투명이라 바탕화면이 비칩니다.
- 노트 색을 바꾸면 접힘 파일도 같은 색으로 바꿔야 합니다. 붙이는 방법은 3장을 참고하세요.

## 3. 접힌 모서리 붙이는 법 (중요)

노트 배경이 오른쪽 아래 28×28 칸을 칠하면 안 되고, 그 칸은 접힘 이미지가 채웁니다. 노트의 `background`를 3겹으로 쓰면 됩니다.

```css
/* 구현 참고 — 노랑 노트 예시 */
.sticky-note {
  --fold: calc(28px * var(--zoom, 1));
  border-radius: calc(12px * var(--zoom, 1));
  background:
    url("icons/fold-yellow.svg") right bottom / var(--fold) var(--fold) no-repeat,
    linear-gradient(#FDF2C2 0 0) left top / calc(100% - var(--fold) + 1px) 100% no-repeat,
    linear-gradient(#FDF2C2 0 0) left top / 100% calc(100% - var(--fold) + 1px) no-repeat;
  filter: drop-shadow(0 4px 10px rgba(31,47,69,.08)) drop-shadow(0 1px 2px rgba(31,47,69,.05));
}
```

- `background-color`나 단색 `background`를 쓰면 잘린 모서리까지 칠해지므로 쓰지 마세요.
- 그림자는 `box-shadow` 대신 `filter: drop-shadow`를 쓰세요. 잘린 모서리 모양을 따라갑니다.
- `+ 1px`는 확대·축소할 때 이음매에 틈이 생기지 않게 하려는 겹침입니다.
- `mask-image`로 모서리를 자르는 방식은 Chromium에서 `file://`로 열었을 때 마스크 이미지가 로드되지 않았습니다(테스트함). 위 `background` 방식을 쓰세요.
- 노트 안의 `textarea` 등은 배경을 투명으로 유지하세요.
- 현재 오른쪽 아래에 있는 `⋰` 리사이즈 핸들은 접힌 모서리와 겹칩니다. 접힌 모서리 영역 자체를 리사이즈 손잡이(`cursor: nwse-resize`)로 쓰는 것을 권장합니다.

## 6. 팝업 메뉴 (쪽지 추가 · 설정 · 종료)

### 6-1. 메뉴 구성

```
[메인 메뉴]                              [추가 팝업]  ← '쪽지 추가'를 클릭하면 오른쪽에 열림
 add-note.svg   쪽지 추가   chevron.svg  →   add-memo.svg    메모 추가
 settings.svg   설정        chevron.svg      add-image.svg   이미지 추가
 ─────────── 구분선 ───────────               add-file.svg    파일 추가
 power.svg      종료
```

- '설정 ›'의 하위 메뉴는 시안에 없습니다.
- 메뉴를 여는 방법(예: 빈 곳 우클릭)은 시안에 나와 있지 않습니다.

### 6-2. 파일별 기능 — 24px

| 파일 | 모양 | 들어가는 곳 | 색 |
|---|---|---|---|
| `add-note.svg` | 글줄 3개가 있는 종이 (오른쪽 위가 살짝 잘림) | 메인 메뉴 '쪽지 추가' | 크림 `#F9ECD8` |
| `settings.svg` | 톱니바퀴 (톱니 6개) | 메인 메뉴 '설정' | 밝은 회색 `#BEC7D4` |
| `power.svg` | 전원 기호 | 메인 메뉴 맨 아래 '종료' (구분선 아래) | 빨강 `#F87171` |
| `add-memo.svg` | 연필 | 추가 팝업 '메모 추가' | 파랑 `#94C7F8` |
| `add-image.svg` | 해와 산이 그려진 액자 | 추가 팝업 '이미지 추가' | 민트 `#9EDCCB` |
| `add-file.svg` | 귀퉁이가 접힌 종이 | 추가 팝업 '파일 추가' | 보라 `#BEB1FA` |
| `chevron.svg` (기존) | › 화살표 | 하위 메뉴가 있는 항목 오른쪽 ('쪽지 추가', '설정') | 연회색 `#B9BDC3` |

- 모두 24×24이고 그림 크기는 약 19~20px입니다. 기존 우클릭 메뉴 아이콘 칸(`.context-menu-icon`, 24px)에 그대로 넣으면 됩니다. 화살표는 기존처럼 22px.
- 글줄·해·산·접힘·톱니 가운데는 **투명 구멍**이라 메뉴 배경색이 비칩니다. 배경색을 바꿔도 아이콘은 그대로 쓸 수 있습니다.
- 호버 때도 아이콘 색은 바꾸지 않습니다(시안도 동일). 기존 우클릭 메뉴처럼 `filter: brightness(1.2)` 정도는 괜찮습니다.
- 쪽지(크림)·메모(파랑)·이미지(민트)·파일(보라) 아이콘 색은 포스트잇 노트 색(노랑·파랑·초록·보라)과 짝을 이룹니다.

### 6-3. 팝업 틀 — 이미지 없음, CSS로 구현

배경 칸·구분선·호버 배경은 메뉴 크기에 맞춰 늘어나야 하므로 이미지로 만들지 않았습니다. 시안 그림에서 잰 값입니다.

| 항목 | 값 | 비고 |
|---|---|---|
| 메뉴 배경 | `#283038` | 모서리 6px, 위아래 여백 6px, 그림자 `0 8px 24px rgba(15,23,42,.16)` |
| 호버 배경 | `#3A4450` | 항목 좌우 8px 안쪽, 모서리 6px (둥근 알약 모양) |
| 구분선 | `#CBD5E1`, 불투명도 14% | 높이 1px, 좌우 20px 안쪽 |
| 글자 | `#FFFFFF` | '종료'도 글자는 흰색, 아이콘만 빨강 |
| 크기 | 폭 240px, 항목 높이 36px | 시안에 적힌 예시 값 |
| 아이콘–글자 간격 | 14px | 기존 우클릭 메뉴와 동일 |

- 시안 색상표의 `#1E1E1E`(메뉴)·`#2A2F36`(호버)는 시안 그림보다 어둡게 적혀 있어서, 그림에서 잰 값을 적었습니다.
- 기존 우클릭 메뉴(`#context-menu`)는 배경 `#373B42`, 호버 `#4A5568`로 이보다 밝습니다. 두 메뉴를 같은 색으로 맞출지는 사용자에게 확인하세요.

### 6-5. 시안과 다르게 정한 점

- 시안의 '팝업 메뉴 예시' 그림에는 쪽지 추가·메모 추가 아이콘이 흰색으로 그려져 있지만, 아이콘 명세인 '아이콘 (개별)' 칸의 색(크림·파랑)을 따랐습니다. 흰색이 필요하면 SVG의 `fill` 값만 `#E5E7EB`로 바꾸면 됩니다.
- 화살표는 시안에서 흰색이지만 기존 우클릭 메뉴와 맞추려고 기존 `chevron.svg`를 그대로 씁니다.

## 7. 설정 창

### 7-1. 여는 방법과 틀

- 바탕 우클릭 메뉴의 '설정'을 누르면 화면 가운데에 설정 창이 열립니다. 하위 메뉴 대신 창을 여는 것이므로 '설정' 오른쪽의 `›`는 빼는 것을 권장합니다.
- 창이 열리면 뒤의 캔버스를 시안 배경처럼 흐리게 덮습니다: 덮개 `rgba(245,247,249,.35)` + `backdrop-filter: blur(8px)`.
- 닫기: 오른쪽 위 X(`close.svg`), Esc, 창 밖 클릭.
- 창 크기는 시안 그대로 944 × 895입니다. 화면이 작으면(Windows 배율 150% 등) `width: min(944px, 100vw - 48px)`, `height: min(895px, 100vh - 48px)`로 줄이고, 오른쪽 내용만 세로로 스크롤합니다(사이드바는 고정).
- 캔버스 확대 배율과 무관하므로 zoom을 곱하지 않습니다.

## 10. 참고 — 쪽지 애니메이션 (`code/animation`)

- `code/animation/note-animations.css`·`note-animations.js`: 쪽지를 추가하면 붙이기(0.45초), 지우면 떼기(0.28초)를 재생합니다. `index.html`에서 두 파일을 불러오며, `renderer.js`·`styles.css`는 고치지 않았습니다.

- 빼려면 `index.html`에서 두 파일을 불러오는 두 줄만 지우면 됩니다.

**묶음 풀기 (`group-animations.css`·`group-animations.js`)** — 15장의 파일 묶음을 풀 때 재생합니다.

- 묶음 포스트잇: **풀기**(0.3초) — 접힌 모서리가 먼저 펴지고(0.14초), 이어서 종이가 조금 커지며 그림자와 함께 사라집니다. 쪽지 '떼기'와 달리 들어올리지 않습니다.
- 담겨 있던 파일: **내려앉기**(0.28초) — 살짝 떠 있던 것이 제자리 크기로 앉습니다. 왼쪽 위부터 0.02초씩 차례로(최대 0.18초).
- 파일의 자리(`left`·`top`)는 건드리지 않고 `scale`·`translate`만 씁니다. 앱이 쓰는 `transform`(묶음을 고르면 담긴 파일이 떠오름 — `styles/groups.css`의 `.group-lifted`)과 겹치지 않게 하려는 것입니다.
- 재생 시점: 화면에서 `.board-group`이 사라지고, 같은 때에 `.file-icon`에서 `in-group`이 떨어지는 것을 보고 정합니다(`renderer/groups.js`의 `ungroup()` 순서 그대로). 되돌리기처럼 지웠다가 바로 다시 그리는 경우와 '동작 줄이기'를 켠 경우에는 재생하지 않습니다.
- 기대는 이름: `#ui-layer` · `.board-group` · `.file-icon`(묶음 안에 있는 동안 `in-group`) · `--fold` · `--z` · `--zoom`. 이 이름이 바뀌면 오류 없이 애니메이션만 멈춥니다.
- 빼려면 `index.html`에서 이 두 파일을 불러오는 두 줄을 지우면 됩니다.

## 12. 판 — 캘린더 · 연대표 (`code/icons`의 판 아이콘)

판(board)은 **캔버스 위에 놓이는 큰 틀**입니다. 쪽지를 판에 올리면 그 자리(날짜·칸)에 붙고, 판을 옮기면 붙어 있는 쪽지도 함께 움직입니다.
판 자체는 이미지가 아니라 CSS로 그립니다. 아래 값은 모두 zoom 1 기준이고, 캔버스 배율을 곱해서 씁니다(쪽지와 같은 방식).

- 고르면 우클릭한 자리에 판이 생깁니다. 판은 쪽지보다 아래(`z-index`)에 두고, 판 위 쪽지는 지금 쪽지 규칙대로 그립니다.

**걸고 옮기는 규칙**

- 막대 아래로 끌어다 놓으면 그 자리에 걸립니다. 좌우로 끌면 캘린더 모드는 하루 단위, 직접 모드는 칸 안 아무 자리로 갑니다.
- 옆 쪽지와 가로로 겹치면 줄이 길어져 아래층에 걸리고, 판 높이도 따라 늘어납니다.
- 판 밖으로 끌어내면 날짜(또는 칸)가 떨어지고 보통 쪽지가 됩니다.

**판 메뉴 (연대표)** — `edit`(이름 바꾸기) · `menu-axis`(시간 축 › 직접 작성/캘린더) · `menu-scale`(눈금 단위 › 연/월/일) · `menu-link`(캘린더 판 연동) · `menu-today`(오늘로 이동) · 구분선 · `pin`(판 잠금) · `trash`(판 지우기)

### 12-8. 확인이 필요한 것

- 캘린더 판의 칸 크기(180 × 148)와 칸 속 쪽지 크기(164 × 120)는 '작게(200 × 150)' 쪽지가 줄어드는 크기입니다. 설정의 기본 쪽지 크기를 '크게'로 쓰는 사용자를 위해 판 크기를 키우면 칸도 같이 커집니다.
- 연대표 '기간 띠'는 제안입니다. 빼도 나머지는 그대로 동작합니다.
- 공휴일 자료를 어디서 받아올지(무료 ics / 공공데이터포털)와 나라 목록.

### 14-3. 바꾸는 법

`renderer/file-icon.js`의 `fallbackIcon()`이 data URL을 만드는 대신 파일 경로를 돌려주면 됩니다.

```js
// 구현 참고 — 종류 이름이 파일 이름과 1:1 (file → other)
export function fallbackIcon(file = {}, dark = false) {
  const kind = fileKind(file.name, file.isDir);          // folder·image·video·audio·sheet·slide·doc·code·zip·app·file
  const name = kind === 'file' ? 'other' : kind;
  return `${ICON_DIR}file-${name}${dark ? '-dark' : ''}.svg`;
}
```

- 파일 이름 글씨는 지금처럼 앱이 그립니다(아이콘 안에 글자는 없습니다).
- 확장자 분류(`KINDS`)는 그대로 두면 되고, 종류를 더 나누고 싶으면(예: PDF를 따로) 말씀해 주시면 그림을 더 만들겠습니다.

## 19. 자 (맞춰 붙기)

## 20. 쪽지 속 링크 · 영상 · 사진

쪽지 글에 인터넷 주소를 적으면 글 밑에 보여 줍니다. 코드는 `renderer/note-links.js`, 모양은 `styles/note-links.css`.

- 보기 방식: **영상 · 사진 바로 보기**(기본) — 유튜브 · 비메오는 쪽지 안 재생기, 영상 파일 주소(.mp4 · .webm …)는 영상, 사진 주소(.png · .jpg · .gif …)는 사진, 그 밖의 주소는 링크 한 줄 / **링크만** — 모두 링크 한 줄
- 설정 › 쪽지 › 쪽지 속 링크 가 기본, 쪽지마다 우클릭 › **링크 보기 ›** 로 바꿈 (주소가 있는 쪽지에만 보임). 한 쪽지에 4개까지
- 링크를 누르면 기본 브라우저에서 엶. 재생기의 '유튜브에서 보기' 도 브라우저로 (캔버스 화면은 다른 주소로 넘어가지 않음)
- 쪽지 크기는 글 + 영상 · 사진에 맞춰 아래로 늘어남 (영상 재생기 16:9, 영상 파일 · 사진은 불러온 뒤 제 비율)
- 유튜브 · 비메오 재생기는 누를 때 불러옴 — 그 전에는 미리보기 그림(유튜브, 비메오는 검은 판) 가운데 재생 단추
  (46 × 32, 모서리 9, 검정 62% · 호버 85%, 흰 ▶). 재생기는 하나마다 화면 프로세스를 따로 써서 (재생 중 140MB 안팎) 누르기 전에는 만들지 않음
